# ValuableList

ValuableList is a simple client-side mod that adds a menu that lists all available valuables on the level, grouped by room, showing each item name and its current value (with cart/extraction items highlighted). It also includes search, a `collected/total` counter, and auto-scrolls to your current room when opened. Open it with `N` (configurable).

It also has an option (disabled by default) that says what is the most expensive item in the current room.

It requires [MenuLib](https://thunderstore.io/c/repo/p/nickklmao/MenuLib/) mod to be installed.

# Список ценностей

Это простой клиентский мод, который добавляет меню со списком всех пристутствующих ценностей на уровне, сгруппированных по комнатам, с названием каждого предмета и его текущей стоимостью в `$` (ценности в тележке/у точки эвакуации подсвечиваются). В этом моде также есть поиск, счётчик `собрано/всего` и автопрокрутка к вашей текущей комнате при открытии. Открыть меню можно нажав на `N` (клавишу можно поменять в конфиге BepInEx). 

В этом моде также есть опция (по умолчанию выключена) которая показывает самый дорогой предмет в данной комнате.

Этот мод требует чтобы [MenuLib](https://thunderstore.io/c/repo/p/nickklmao/MenuLib/) был установлен.
